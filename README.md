# PS VR2 OLED Test

Веб-тест для быстрой проверки OLED-дисплеев гарнитуры **PlayStation VR2** на битые, застрявшие и неисправные пиксели.

🌐 **Онлайн:**  
https://akik40792-cloud.github.io/PSVR2-OLED-Test/

## Возможности

- ⚫ BLACK — проверка чёрного
- ⚪ WHITE — проверка белого
- 🔴 RED — проверка красного субпикселя
- 🟢 GREEN — проверка зелёного субпикселя
- 🔵 BLUE — проверка синего субпикселя
- 🤖 AUTO — автоматическая последовательная проверка всех цветов
- ⏱ 15 секунд на каждый цвет
- 🎮 Управление с DualSense
- ⬅️➡️ Выбор цвета с D-pad / левого стика
- ✕ Запуск выбранного теста
- 🌐 Автоматический выбор языка по настройкам браузера
- 👁 Счётчик просмотров страницы
- 📱 Адаптивный интерфейс

## AUTO

Режим **AUTO** автоматически запускает полный цикл проверки:

**BLACK → WHITE → RED → GREEN → BLUE**

Каждый цвет отображается в течение **15 секунд**.

Общее время полного цикла:

**5 × 15 = 75 секунд**

После завершения теста автоматически открывается меню выбора цвета.

## Чистый OLED-тест

Во время отображения тестового цвета на экране **нет никаких элементов интерфейса**:

- нет текста;
- нет таймера;
- нет кнопок;
- нет рамок;
- нет меню;
- нет индикаторов.

Это позволяет проверять OLED-матрицу на чистом однотонном фоне.

## Что можно обнаружить

Тест помогает обнаружить:

- битые пиксели;
- постоянно светящиеся пиксели;
- застрявшие пиксели;
- дефекты отдельных RGB-субпикселей;
- неоднородность изображения;
- отдельные светлые или тёмные точки.

Для поиска дефектов рекомендуется медленно осматривать всю площадь изображения через линзы PS VR2.

## Управление

### DualSense

**D-pad / левый стик**  
Выбор цвета.

**✕**  
Запуск теста.

### Клавиатура

**← ↑ ↓ →**  
Выбор цвета.

**Enter / Space**  
Запуск теста.

**Esc / M**  
Возврат в меню.

## Автоматический язык

Язык интерфейса определяется автоматически по настройкам браузера.

Если язык браузера начинается с `ru`, используется русский интерфейс.

Для английского и других языков используется английский интерфейс.

Ручного переключения языка нет.

## Счётчик просмотров

В нижней части главного меню отображается количество просмотров страницы.

Счётчик не отображается во время OLED-теста.

Для подсчёта используется внешний сервис **Hits.sh**.
